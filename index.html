Unit 1 — Introduction to HTML

Learning Objectives

  • Understand the structure of an HTML document
  • Use common tags: headings, paragraphs, lists, links, images
  • Create simple forms and tables

Topics

  1. HTML document structure (<!doctype>, <html>, <head>, <body>)
  2. Text elements: <h1>..</h1>, <p>, <strong>, <em>
  3. Lists: ordered (<ol>) and unordered (<ul>)
  4. Links and images: <a>, <img>
  5. Basic form: <form> with <input> and <button>

Example: A small contact form

Exercises

  1. Build a simple profile page with a picture, bio, and list of hobbies.
  2. Create a product table using the <table> tag.
